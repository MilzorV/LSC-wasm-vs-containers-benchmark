# Archive

Historical Meilisearch-era crates kept for reference. They are not part of the
active movie-search benchmark workspace.

- `spin-meili/crates/legacy-subset-core` — custom Meilisearch-compatible subset
- `spin-meili/crates/meili-wasi-compat` — upstream Meilisearch WASI port scaffolding
- `spin-meili/crates/storage-memory` — in-memory storage helper for the subset

Upstream feasibility evidence lives in [`docs/upstream-wasi-blockers.md`](../docs/upstream-wasi-blockers.md)
and the scripts under [`scripts/`](../scripts/).
